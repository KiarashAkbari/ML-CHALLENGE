### 1. این فایل برای چیست

این فایل را از روز اول تا روز تحویل نگه می دارم و هر بار که چیزی تمام شد وضعیتش را عوض می کنم. هر الزام یک شاهد دارد و اگر شاهدش را نتوانم نشان بدهم آن الزام تمام نشده حساب می شود. تصمیم ها و فرض هایم هم همین جا ثبت می شوند که موقع نوشتن report و موقع دفاع چیزی از یادم نرود.

### 2. قاعده هایی که برای خودم گذاشتم

- عددی را توی report نمی نویسم که از اجرای واقعی نوت بوک نیامده باشد. اگر ندارم می نویسم باید اندازه گیری شود.
- هر فرض را همین جا می نویسم تا بعدا یا تایید شود یا رد.
- توضیح ها و سلول های Markdown فارسی اند. اسم متغیر و تابع و کلاس، docstring و commit message انگلیسی اند.
- هر کمکی که از هوش مصنوعی می گیرم را همان لحظه توی بخش AI usage این فایل ثبت می کنم.
- منطق قرنطینه و manifest به دریافت HTTP و نوشتن روی دیسک وابسته نباشد، چون مرحله 2 و 3 روی همین package ساخته می شوند.
- بازتولید پیش شرط است. اگر روی ماشین ارزیاب اجرا نشود بقیه چیزها نمره نمی گیرند.
